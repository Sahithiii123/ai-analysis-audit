UCI describes Bank Marketing as 45,211 instances with 16 features plus the target; the downloaded file has 17 columns. OpenML describes Telco as 7,043 instances and 20 features; its ARFF file has 21 attributes, including the target. UCBAdmissions is a 24-cell contingency table (two admission outcomes, two genders, six departments); the source CSV's `rownames` index is excluded only from the reported analysis-column count. No filtering or data transformation was performed. Cite Bickel, Hammel, and O'Connell (1975) for Berkeley admissions and Fisher (1936) for Iris.

The downloader stops on a failed request or invalid file and does not substitute data. The Olist retrieval timestamp comes from the recorded download manifest; the five CSVs are present in the user-provided ZIP and their hashes match the case result record, but they are absent from the extracted working tree. The current Kaggle license could not be verified from authenticated metadata because the TLS request failed; treat it as unverified and verify current Kaggle terms before redistribution. The OpenML `Public` value is an access/license label, not a specific license grant; the Telco upstream Kaggle terms were not independently established here. The UCBAdmissions source does not state a dataset-specific license, so the R package license is not presented as a license for the data itself.
